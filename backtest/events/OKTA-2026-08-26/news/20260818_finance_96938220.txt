Centralizing access control, eliminating local credential management, and aligning storage administration with corporate SSO policies.
SANTA CLARA, Calif., August 18, 2026--(BUSINESS WIRE)--Lightbits Labs®, inventor of the NVMe® over TCP storage protocol and Inferra™, intelligent KV cache orchestration engine, today announced native integration with Okta in Lightbits software release v3.20.1. This enhancement streamlines storage security for enterprise customers, including one of the world's largest US-based financial services providers.
Okta (Nasdaq: OKTA), a leading identity and access management company based in San Francisco, Calif., provides cloud software that helps companies manage and secure user authentication and for developers to build identity controls into applications. Building on the federated authentication foundation that Lightbits established with Active Directory Federation Services (ADFS), the native Okta integration allows organizations to manage cluster access through their standardized identity provider rather than maintaining local user accounts. Storage administrators can now authenticate to the cluster via the CLI using their organization's existing Okta identities and, in the future, via the REST API. Instead of relying on local user accounts and manual token/JWT management, cluster administrators can assign roles directly to Okta users and groups already governed by corporate security teams, centralizing access control and aligning storage administration with corporate SSO and compliance policies.
"Now more than ever before, enterprises require a unified approach to identity governance across every layer of their data infrastructure," said Abel Gordon, Chief Technology Officer at Lightbits Labs. "Expanding our federated identity capabilities to include Okta empowers our customers—including major global financial institutions—to maintain rigid security postures effortlessly while accelerating operational productivity."
Enhanced security controls:
-       Simplified Authentication & Authorization: Connects Lightbits directly to the organization's existing Okta identity provider, unifying storage administration under corporate SSO standards.
-       Streamlined Credential Lifecycle Management: Eliminates local user accounts and manual JWT/token maintenance by allowing role assignments to Okta users and groups managed by security teams.
-       Unified Interface Access: Enables secure, centralized authentication across both the CLI and REST API interfaces using existing enterprise credentials.
