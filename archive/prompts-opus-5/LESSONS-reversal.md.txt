# Lessons — stage R

**Deliberately empty. Nothing has resolved.**

This file exists so the `reversal-hunter` contract can name it, and so the
`pre_lessons` control has something to be a control over. Every rule that lands here
must be paid for by a resolved run and scored by `rev_resolve.py`, the way
`researcher_us/LESSONS.md` was grown from `edge_postmortem.py`.

Two things that must NOT be written here:

**Anything from phase 0.** The base rates in `README.md` are facts about the market,
not guidance for a hunter, and they are already in the agent's own brief where they
belong. A lesson is something a resolved hunt taught.

**Anything a company-specific post-mortem produced.** `researcher_us/LESSONS.md` holds
patterns that repeated across several days with no company fixes in them, and it is
short for that reason. One name behaving oddly once is not a lesson.

The hunter reads this file **after** it has sized the name once and frozen that draft
into `pre_lessons`. That order is what makes the file measurable: a rule that costs
rank correlation shows up within a few resolved days instead of accumulating forever.
