# Lessons — stage IPO

**Deliberately empty. Nothing has resolved for this stage.**

This file exists so `unpriced-hunter-ipo` has something to read after its frozen draft,
and so the `pre_lessons` control is live from the first run: a hunter that reads an
empty file emits `pre_lessons` equal to its final set, which is the correct measurement
of a file that says nothing, not a missing measurement.

Rules go in here only when resolved IPO runs have paid for them, pooled over many days
(`researcher_ipo/scripts/ipo_resolve.py --pool`), because at about one event a session a
single day settles nothing. Do not copy `researcher_us/LESSONS.md` across: its rules were
bought on earnings prints against a consensus, and neither a debut nor a lock-up has one.
The phase 0 base rates are not lessons either; they are in every baseline under `phase0`.
