# The first brief, kept so the change is inspectable

These two hunts were run on 2026-09-22 under the FIRST version of `reversal-hunter`,
which asked whether yesterday's fall "overshot what the news justified". That question
was replaced the same day: it is backward-looking, unanswerable before the outcome, and
the fall is the hunter's own input, so hindsight is structural.

The replacement asks forward — is there more bad news coming that the price does not
hold, or is it finished — and every finding must name a dated future development with a
document behind it.

Both files are kept because the same two names were re-hunted under the new brief, so
the pair is the only direct read this repo has on what the reframing changed. Neither
set is evidence about the stage: two names is not a ranking, and nothing has resolved.
