# The second brief: forward only, no repricing leg

These two hunts ran under v2, which asked only "is there more bad news coming that the
price does not yet hold, or is the bad news finished". They are good hunts — CUE found
4,090,908 resale-registered warrant shares free of lock-up, SCTX established that no
dilution mechanism structurally exists — and they are kept because the same two names
were re-hunted under v3 the same day, so the pair shows what adding the second leg buys.

What v2 could not express: a fall that was simply too big. It had to file any such
judgement as colour rather than as a sized finding, because the brief had no leg for it.

v3 asks both legs inside the same short window, and makes the repricing leg answerable
by requiring a named `mechanism_in_window` — the specific thing that closes the gap
before the next close. Without one, an overshoot is an opinion and the brief says to drop
it or file it outside the window.
