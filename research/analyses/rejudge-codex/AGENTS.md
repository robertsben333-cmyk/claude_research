# Rules for any Codex task in research/analyses/rejudge-codex/

This folder is a blind re-judge: a model sizes earnings evidence that was collected
before the outcome existed. The rest of this repository holds those outcomes (prices,
resolved moves, other models' verdicts, notes that quote results), so the experiment is
only worth anything if the task never opens them. The task prompt is `PROMPT.md` in this
folder; its list of allowed paths is the whole list.
